把实景三维链路里只能靠商业软件点鼠标的环节，做成可脚本化的工具

四个面向实景三维生产的开源项目：三维模型转正射影像、正射影像建筑物轮廓提取、 建筑物分割模型训练、无人机视频融合投射。全部以 MIT 协议开源。

GitHub Markdown 版

项目

ObjOrthoRender
OBJ 三维模型转带地理参考的正射影像

倾斜摄影生产链里，模型通常停留在三维。制图、变化检测、建筑物提取都需要二维正射影像。这个工具把「三维模型 → 带坐标系的 GeoTIFF」这一步做成了命令行操作。

正射影像 DOM 数字正射影像图 OBJ 转 GeoTIFF
Footprint-Creater
正射影像自动提取建筑物轮廓

给一张带地理参考的正射影像，输出建筑物轮廓 Shapefile。和「跑个分割模型就完事」的区别在于后处理：从像素掩码到可入库的图斑，中间还有校验和规则化两步。

建筑物轮廓提取 建筑物提取 房屋面提取 建筑图斑
HRNet-Footprint-Trainer
在自有影像上训练建筑物分割模型

公开数据集上训好的模型，换到你的城市就未必准。这个仓库把「大影像加矢量标签 → 切片数据集 → 训练 → 大图推理」整条链路补齐了。

建筑物分割训练 语义分割训练 HRNet-W48 MMSegmentation
VideoFusion-Web
无人机视频融合投射到三维实景

与其在角落放个小窗让操作员心算对应关系，不如把画面按相机位姿投影到模型表面 —— 画面和地物处在同一空间，遮挡、朝向、覆盖范围全部自洽。

视频融合 视频投射 视频投影 无人机视频

关于

这些工具都来自实际生产中的卡点：批处理几千个模型、在没有显卡的服务器上出图、 让矢量化结果真的能入库、把无人机画面投到三维场景上。如果你也遇到同样的问题，欢迎在仓库提 Issue。
